# Деплой на VPS

Скрипт [deploy.py](deploy.py) собирает сайт и передаёт только папку `dist` на VPS. На чистом сервере он создаёт отдельный сайт Nginx и выпускает HTTPS-сертификат Let's Encrypt. Если VPS уже использует `caddy-naive` для VPN, скрипт добавляет только изолированный блок сайта в Caddy и выполняет его штатную горячую перезагрузку.

Он не редактирует настройки VPN, бота, Docker и других доменов. На сервере изменяются только:

- `/var/www/dianavolf.ru` (или путь `remote_root` из конфига);
- `/etc/nginx/sites-available/dianavolf.ru` и симлинк в `sites-enabled` на сервере без Caddy;
- либо один помеченный блок `dianavolf.ru` в Caddyfile на сервере с `caddy-naive`;
- пакеты `nginx`, `certbot`, `python3-certbot-nginx` — только на сервере без Caddy.

## Один раз перед первым деплоем

1. В панели домена создайте A-запись: `dianavolf.ru` → публичный IPv4 вашего VPS. Если включаете `include_www`, добавьте также `www`.
2. Убедитесь, что порты 80 и 443 открыты в firewall/VPS-панели. Это нужно Nginx и Let's Encrypt; работающий VPN на другом домене скрипт не меняет.
3. На компьютере должны быть Node.js, Python 3 и OpenSSH Client (`ssh`, `scp`).
4. На VPS нужен пользователь с SSH-ключом и `sudo` без запроса пароля. Либо укажите в конфиге `user: "root"`.
5. Скопируйте `deploy.config.example.json` в `deploy.config.json` и заполните реальными данными. `deploy.config.json` не добавляйте в Git.

## Запуск

```powershell
Copy-Item deploy.config.example.json deploy.config.json
# отредактируйте deploy.config.json
python deploy.py --config deploy.config.json
```

При каждом следующем запуске сайт пересобирается и выпускается новая папка-релиз. Активная версия переключается симлинком `current`, поэтому загрузка файлов не оставляет сайт в полусобранном состоянии.

## Если сертификат не выпускается

Проверьте, что A-запись уже успела обновиться и `dianavolf.ru` открывается по HTTP с VPS. Обычно мешают закрытые порты 80/443 или другой Nginx-конфиг, уже назначенный этому же домену. Скрипт остановится с ошибкой и не будет трогать VPN.
