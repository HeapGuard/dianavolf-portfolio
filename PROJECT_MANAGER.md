# Как добавить работу самостоятельно

1. В PowerShell из папки сайта запусти:

   ```powershell
   python project_manager.py
   ```

2. Откроется локальная страница `http://127.0.0.1:8765`. Заполни форму. В полях изображений укажи полный путь к файлу, например `A:\Работы\Кофейня\01.jpg`. Путь к обложке обязателен, остальные изображения — по одному в строке.
3. Нажми «Добавить в сайт». Картинки скопируются в `public/projects/<id>`, а информация о работе появится в `src/data/user-projects.ts`.
4. Опубликуй изменения:

   ```powershell
   python deploy.py --config deploy.config.json
   ```

`ID` — короткое уникальное имя латиницей, например `coffee-brand` или `poster-2026`. Окно с формой можно закрыть в любой момент; для остановки локального сервера нажми `Ctrl+C` в PowerShell.
